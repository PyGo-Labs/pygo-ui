# PyGo UI

Official UI component system for the PyGo framework — HTMX + Alpine.js + Tailwind components.

## 🚀 Quick Start

```bash
# Install the module
pygo module install pygo-ui

# Use in your components
pygo new my-app
cd my-app
```

## 🎨 Philosophy

- **Zero complex JavaScript** — HTML over the wire
- **Lightweight & fast** — Only what you need
- **Accessible** — WCAG 2.1 AA compliant
- **Customizable** — Themes, colors, typography

## 📦 Components

| Category | Components |
|----------|-----------|
| **Base** | Button, Input, Textarea, Select, Checkbox, Switch, Card, Modal, Dropdown, Tooltip |
| **Forms** | FormGroup, FileUpload, DatePicker, RichEditor, FormWizard |
| **Data Display** | Table, List, StatCard, Badge, Avatar, Tag, Progress, Skeleton |
| **Navigation** | Navbar, Sidebar, Breadcrumb, Tabs, Pagination, Menu, Stepper |
| **Feedback** | Alert, Toast, Loading, Spinner, EmptyState |
